# Community Intentions

Community intentions are named, reusable configurations that combine an
intention type with specific output preferences for a real-world use case.

They work the same way as core intentions — just more specific. Someone
discovers a combination that works well, names it, and shares it. Over time
the community builds a library of patterns that encode real human wisdom
about how to get the most out of agent conversations.

---

## How to contribute

1. Fork this repo
2. Copy `/template/INTENTION.md` into a new folder under `/community/your-intention-name/`
3. Fill it in
4. Open a pull request

The only requirement is that it solves a real, recurring use case — not just a variation for variation's sake.
